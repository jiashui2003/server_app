# RetroUI Card Reference

Source: https://www.retroui.dev/docs/components/card

ServerLens 8.0 uses RetroUI as a visual constraint, not as copied runtime code.

- Registry pattern: `npx shadcn@latest add @retroui/card`
- Font direction: `Archivo Black` for display labels and `Space Grotesk` for product text.
- Component feel: black border, hard offset shadow, flat color fills, visible hover/active translation, and terse card content.
- Product constraint: keep operational density and defensive server workflow clarity; avoid playful decoration that weakens monitoring.
- 8.0 monitoring constraint: live pulse cards, explicit scroll containers, and wrapped evidence text must stay inside RetroUI card boundaries.
