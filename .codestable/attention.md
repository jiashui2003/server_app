# CodeStable Attention

## Project Constraints

- This is a defensive server status and risk analysis app for authorized servers only.
- First delivery must run locally with demo data and no external services.
- UI direction: macOS/iOS-style product interface, dense but calm, white glass surfaces, dark navigation rail.
- Verification requires `npm.cmd test` and `npm.cmd run build` before any completion claim.

## Commands

- Start app: `npm.cmd start`
- Run tests: `npm.cmd test`
- Build check: `npm.cmd run build`

## Notes

- Keep generated or image-assisted visual assets project-local before referencing them.
- Use CodeStable notes for feature traceability after verified implementation.
